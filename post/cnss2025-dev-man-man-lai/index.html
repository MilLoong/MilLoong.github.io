❓CH1

  • 考虑到 infiniteStream() 是无限流，是一个生成器

想法 1（错解）

  • 它生成的是所有正整数，要想生成特定的斐波那契数列，可以对它进行 filter 过滤，因为有一个定理能够$O(1)$地判断一个数是否是斐波那契数：

    $$ S_{x} = \frac{φ^x - ψ^x}{φ - ψ}\\ 其中φ=\frac{1 + \sqrt{5}}{2}，ψ=1-φ=\frac{1-\sqrt{5}}{2}\\ 那么有：\\ 满足：5n^2+4或5n^2-4其中之一是完全平方数的n，是斐波那契数 $$

    但这样不好处理相同的数的情况，比如斐波那契数就是$A_1=A_2=1$，而 infiniteStream() 里并没有两个 1，这样进行特判不太好

  • 想法 2（正解）

    • 其实很简单，既然不能改变 infiniteStream() 的内部结构，那就在它的外面再套一层生成器就可以了

    • 为了避免重复计算，可以利用 infiniteStream() 生成的正整数序列结合 for 迭代，然后利用斐波那契数列的递推求法就可以解决问题了：

      def infiniteStream():

    n = 1

    while True:

        yield n

        n += 1


def fibStream():

    a,b=0,1

    for _ in infiniteStream():

        yield b

        a,b=b,a+b

分析

这个第二问提示有点明显了，既然是 lazy calculation 那就可以：

  • 先不建当前节点的左子树和右子树
  • 而是保存当前节点的左子树数组和右子树数组
  • 在必要的时候才建子树，并且如果子树已经建好了就不重复建

所以这样的话就给当前节点新增加一个 left_arr 成员和一个 right_arr 成员就好了（实际上就是把原题代码中的局部变量变成节点的成员）

然后就不需要 size 成员了，因为我们可以直接len(self.left_arr)或len(self.right_arr)

所以每个节点成员就变成了：

head

left

right

left_arr

right_arr

Code 

class LazyBST:

    def __init__(self, arr):

        if not arr:

            self.head = None

            self.left = None

            self.right = None

            self.left_arr = None

            self.right_arr = None

        else:

            self.head = arr[0]

            self.left = None

            self.right = None

            self.left_arr = [x for x in arr[1:] if x <= self.head]

            self.right_arr = [x for x in arr[1:] if x > self.head]



    def idx(self, index):

        if index < len(self.left_arr):

            if not self.left:

                self.left = LazyBST(self.left_arr)

            return self.left.idx(index)

        elif index == len(self.left_arr):

            return self.head

        else:

            if not self.right:

                self.right = LazyBST(self.right_arr)

            return self.right.idx(index - len(self.left_arr) - 1)
