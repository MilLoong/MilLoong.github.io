CTFWeb-Python爬虫入门——Bugku秋名山车神

原文：https://blog.csdn.net/qq_30618989/article/details/145620111
此原文也是本人所写

题目网址： Bugku秋名山车神

题目概况：

打开环境后可以发现，是要在2s内计算出表达式的值：

可以看到，没有提交结果按钮的表单，所以猜测是用post请求提交答案，先用 HackBar （当然可以用其他抓包软件）随便post一个键值对，可以得到：

这说明要提交键为value的键值对。但是显然人脑不可能在2s内计算出着一长串的表达式，而且表达式是在响应请求之后才能得到的，所以不能用抓包的方式提交。于是乎，这题就是用Python爬虫来解决。

前置知识：

Python基本语法知识，Python正则表达式（re模块）或者BeautifulSoup模块，Python的requests模块，HTTP相关知识（get请求，post请求，sessions或cookies）

题解：

那么总体的思路就是，先发送get请求给环境，然后找到表达式所对应的区域，把表达式提取出来（可以用re或者Beautifulsoup），然后计算表达式的值，再post请求给环境即可（用Python自带的eval()函数即可计算）。但要注意的是get和post要让服务端知道是一个人发送的，所以要用到sessions或者cookies（不了解相关知识的可以自行百度或者找相关文章看哦，这里不赘述）

两种识别身份的方式（sessions\cookies）：

因为要匹配字段，我们先发送get请求给环境，且下次要让服务端知道是同一个人的发包，于是就要用到sessions或者cookies。

sessions： 

import requests
 
s=requests.session()#新建一个session
 
url="http://117.72.52.127:16037/"#环境的url
 
#接下来就是要用同一个session来进行get和post
 
get_response=s.get(url)
 
#匹配，计算sum......
 
post_response=s.post(url,data={'value':sum})#注意python的键值对（字典）的写法

cookies： 

import requests
 
url="http://117.72.52.127:16037/"#环境的url
 
get_response=requests.get(url)
cookie=get_response.cookies#记录此次get的cookies
 
#匹配，计算sum......
 
post_response=requests.post(url,data={'value':sum},cookies=cookie)#用同一个cookie来post

两种匹配表达式的方式（re/BeautifulSoup）：

要想识别表达式，我们就要先知道表达式在网页源代码中的哪个位置。所以这里先发送get请求并打印得到的信息：

import requests
 
url='http://117.72.52.127:16037/'#环境的url
 
response=requests.get(url)
 
print(response.text)

可以得到：

所以我们能知道，表达式的内容是在…=?;里面的，于是就开始匹配。

re模块： 

import re
 
#注：[^=]+表示匹配至少一个不为'='字符的字符，^表示对字符串取反，而([^=]+)则表示将其分组
#([^=]+)=\?;就是匹配所得表达式的字符串，并将其分组（\?表示转义?）
#.group(1)就是取表达式的字符串，因为group(0)是...=?;全都包含进去了
exp=re.search(r'([^=]+)=\?;',get_response.text).group(1)
 
#用eval计算表达式的值
sum=eval(exp)

BeautifulSoup模块： 

from bs4 import BeautifulSoup
 
#用BeautifulSoup来解析HTML
soup=BeautifulSoup(get_response,'html-parser')
 
#soup.find('div')指查找div标签所在位置（返回...的字符串）
#.split('=')[0]指以=进行分割，并取第一个字符串
exp=soup.find('div').text.split('=')[0]
 
sum=eval(exp)

完整代码（用的是sessions和re）： 

import requests
import re
 
url='http://117.72.52.127:18450/'#环境的url
 
s=requests.session()
 
get_response=s.get(url)
 
exp=re.search(r'([^=]+)=\?;',get_response.text).group(1)
 
sum=eval(exp)
 
post_response=s.post(url,data={'value':sum})
 
print(post_response.text)
