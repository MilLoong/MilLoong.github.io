Windows和Linux（本篇讲WSL）中vscode安装及使用教程

原文：https://blog.csdn.net/qq_30618989/article/details/145636234
此原文也是本人所写

前言：

说到文本编辑工具，相信大多数人对vscode并不陌生。虽然vscode确实有些年代了，但是其自身拥有的拓展，编辑代码的手感等等还是让许多人坚持使用。所以本篇博客给新进入大学的计算机新生以及对vscode的热爱但不会安装和使用的爱好者提供vscode的使用教程。而且还有一个原因就是，作者在网上看到的文章专业语言有点多，不适合新手阅读，导致我也是逐渐摸索才找到正确使用方法的，所以在此写一篇文章进行总结，如有不对之处，希望读者指正。

vscode配置：

vscode是一个很高级的编辑器，但并不是一个编译器。换句话说，相当于一个高级的记事本，只能用来编写代码，而不自带运行，编译和调试。所以，我们需要安装编译器来配置语言环境。这里在windows下最常用的是MinGW（也就是gcc的windows版本）。

MinGW-w64下载：

MinGW在其他文章中可能会推荐在 mingw官网 下载，不过实际上，这个MinGW原始项目已经停止维护，官网也进不了了。所以这里推荐的是使用MinGW-w64这个拓展版本，它和MinGW的区别在于这个可以支持64位或者32位可执行程序，而MinGW只能支持32位可执行程序。

这里推荐一个 第三方下载网站 。打开后，先不着急下载，按照下面步骤进行安装：

首先进入 Files :

接着进入 Toolchains targetting Win64 ：

然后进入 Personal Builds ：

然后进入 mingw-builds ：

在这里我们选择用8.1.0的版本，因为8.1.0版本针对 x86_64 架构进行了优化，采用 POSIX 线程模型，集成 SEH（结构化异常处理），适用于跨平台开发、高性能计算、嵌入式系统开发等多种场景，且社区支持活跃，简单来讲就是更稳定，更灵活，更高效。

这里选择posix，因为其启用 C++11/C11 多线程功能。

这里选择seh。

然后点击下载即可。

下载完之后可以得到一个压缩包，然后就可以解压到随便一个文件夹了。

配置环境变量：

环境变量 是操作系统中用于指定运行环境的一些参数，是具有特定名称的对象。

在这里我们要配置环境变量中的 path 环境变量 ，其作用简单来讲就是：指定可执行文件的搜索路径。具体来说，如果当前目录下找不到可执行文件，就到 path 路径 去找，这样就会方便找到编译器的一些可执行文件。

比如，可执行文件a.exe在C:\xxx\yyy，没配置 path 变量 前，如果你要执行它，可能要输：

C:\xxx\yyy a

但配置后，你在任何目录下都只需要：

a

那么我们怎么执行hello.exe文件呢？我们先按任意键把刚才生成活动文件时的打开的窗口关掉，然后用ctrl+打开终端。这里的就是ESC下面那个键：

补充： 事实上，还有更简单的方法可以运行C/C++程序。

1. 用之前提到的C/C++ Compile Run插件，直接按F6就可以运行了。

2. 用Code Runner拓展：

  ![](/01_assets/vscode-wsl-tutorial_remote_25.png)

下载之后，右键，Run Code即可运行代码：

3. 在终端直接生成.exe文件。直接在终端利用gcc，输入gcc hello.c -o hello.exe即可生成.exe文件，然后.\hello.exe即可：

在WSL上运行程序：

关于WSL的内容，比如如何安装WSL，本篇文章不涉及。那么要在WSL上运行vscode所写的程序，也就是生成的.exe文件，我们只需要 找到在WSL上对应到windows的文件夹 即可。比如我刚才在C:\test\code里写了hello.exe文件，那么我就要在WSL的对应路径上找到它，找到之后就可以用.\hello.exe来运行了。实际上，windows里的C盘中的文件夹对应到WSL中的路径是在\usr\mnt\c中（D盘在\d，E盘在\e中），那么我们只要找到这个路径即可。

首先我们打开WSL后，默认进入的是\usr文件夹（这里的usr实际上就是你的windows账号的用户名），大概是xxx@xxxx:~$的格式：

xxx@xxx:~$

这时我们用cd/mnt进入mnt文件夹，然后输入cd /c进入c文件夹。接着进入你在windows下对应存放文件的位置，我这里是放在C:\test\code，所以我只要进入cd test\code即可：

xxx@xxx:~$ cd /mnt
xxx@xxx:/mnt$ cd /c
xxx@xxx:/mnt/c$ cd test/code
xxx@xxx:/mnt/c/test/code$

接着用./hello.exe运行程序就好了（ "/" 和 "" 都可以）：

xxx@xxx:/mnt/c/test/code$ ./hello.exe
hello,world.
