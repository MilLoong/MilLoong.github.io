WSL下载，使用の教程

原文：https://blog.csdn.net/qq_30618989/article/details/149073574
此原文也是本人所写

前言

当今最流行的操作系统无疑是微软发布的 Windows系统， 其上面生态丰富，易用，为大众传播最广。但在程序员的世界， Linux系统 同样也是一种生态丰富且易用，简洁的系统，但它相比于 Windows， 具有 更大的优势，因为它是开源的，而Windows不是。 那么开源系统的好处自然不用多说，如果是闭源的，那么遇到一些有关os的情况就不能处理。而且还有一个原因是github上有一些项目只能用Linux运行。

但如上所述，现在主流的系统是 Windows系统， 我们装的系统呢也自然多数是 Windows系统， 那我们如果想要用Linux系统，该怎么做呢？一种是用 虚拟机， 另一种就是本篇文章讲的 WSL。 两者各有优劣，虚拟机的话占内存较大，需要空出许多内存，但功能比较齐全。而WSL的话是比较轻量的，但有些功能可能会没有涉及到。 不过如果是学生党的话，我建议还是直接装WSL就好了，毕竟不花时间，而且我们大多数也只是用到终端的功能。

下载Linux系统

启用了上述选项并生效之后， 我们就可以在 Microsoft Store软件 下载Linux系统了

注：

1、其实按照官网的说法，是可以直接在终端用以下命令安装的：

wsl --install

不过好像是下载源有问题还是什么，博主用这个命令安装得很慢，所以是改用的在Microsoft Store下载安装，如果你用上述命令没有问题的话，那也可以尝试

2、Microsoft Store是Windows系统自带的软件，同样可以直接搜出来

3、如果Microsoft Store无法打开，可以去 官方帮助 去看看能不能解决，如果不行的话，如果出现Microsoft Store初始化失败，可以这样来：

（1）Win+R打开打开 运行

（2）输入inetcpl.cpl然后回车，打开Internet选项窗口

（3）点击上方的 高级

（4）向下滑，找到 安全

（5）把 使用TLS 1.x 的那几个选项全都勾上，如果只有 TLS 1.1 ，那么就会出现问题

如果还是不能解决，Microsoft Store还是抽风的话，可以参考 这篇文章

打开 Microsoft Store ，然后我们要下载 Linux系统 ，当下适合学生党使用的是 Ubuntu系统（就是一种Linux系统了，Linux系统分为好几种） ，当然如果你对 网络安全 感兴趣的话，也可以下 kali ，那么本篇文章讲的是 Ubuntu：

这么多版本中，比较推荐的是比较老的 Ubuntu 20.04.6 LTS ，因为最新的会有些问题，这里不细讲。

或在 Windows终端 打开 ：

创建账户

在弹出的窗口中，等待 加载完毕 后，系统会要求创建一个 新账户和密码， 这里就直接按页面操作就好了，没什么好讲的，操作都是默认，然后就输入账户和密码。

界面大概就是这样的（当然没有后面的#注释就是了）：

Installing, this may take a few minutes...
Please create a default UNIX user account. The username does not need to match your Windows username.
For more information visit: https://aka.ms/wslusers
 
Enter new UNIX username: lilei #用户名
New password:         #密码，无回显
Retype new password: 
passwd: password updated successfully
Installation successful!

注：

1、创建密码时，密码的输入是没有回显的，就是说你在界面上看不到密码的输入的，这是系统的一种安全措施，不是出错了，要注意，所以一定要记住你打了什么，你的密码是什么。

如果实在是忘了密码，可以参考 这个教程

2、忘了用户名，可以在终端中用：

whoami

使用

gcc

如果不知道 gcc 是什么的话，请自行搜索了解，本文不涉及。

在 Linux 中安装 gcc 是及其方便的，只需要输入如下命令：

sudo apt update    #更新
sudo apt install build-essential    #安装gcc（实际是整个开发工具集）

然后的话就默认安装就好了。

可以通过：

gcc -v

python

Ubuntu系统 是自带 python3 的，可以用：

python3 -v

来看版本，是否安装什么的。

而不一定有 python2， 如果要安装的话可以这样 ：

sudo apt update
sudo apt install python2

然后看版本：

python2 -v
