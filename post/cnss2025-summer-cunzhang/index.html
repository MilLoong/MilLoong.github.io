👴村长的烦恼

✍CH1

1

  • **Q: **在第二种田地的分配方式中， B村民眼里的第b23是实际农田中的第几号block？

    A: B村民的开头是block32，所以b23是block(32+23)=block55

  • **Q: **观察 23 和 实际block序号 的二进制，有什么规律？

    A: $(23)_{10}=(10111)_{2}$，$(55)_{10}=(110111)_{2}$，可以发现其实就是在23的二进制位的最高位的下一位加上一个 1 。

    其实这是显然的，因为页面大小是$(32)_{10}=(100000)_{2}$，刚好是 2 的整数次幂（$2^{5}$），所以当然会在第五位+1。

    但这个规律可以更强一点：若页面大小是$2^{k}$，那么村民A/B的相对编号（虚拟地址）就是实际编号（物理地址）的前k位，而实际编号（物理地址）从第k+1位起的部分就是页码

  • **Q: **根据这个规律，你能帮村长找出一个快速将 A，B村民眼里的block序号翻译成实际农田的block序号的方法吗？

    **A: **根据上一问的规律，村长只需要知道 A，B村民被分到了哪一页即可，也就是知道页码。比如：

    相对编号是：relative_num，页码是：page，页面大小是：size，实际编号是：real_num，那么有：

    $$ real\_num=page*size+relative\_num $$

​ 若$size=2^k$，那么有：

$$ real\_num = (page << k) | relative\_num $$

  • **Q: **想出一个在减少 record 使用 和 减少空置block 中作出平衡的方案，将这个方案弄成代码更改到GiveBlockTo函数上。（可以结合第一问的快速翻译思考一下）

    **A: **

    • 思考：

      大概整理一下条件，发现：

      • Recorder所在的区域不能动
      • 不应把 B 村民的土地混入 A 村民的页面，不然其实是内存分段，肯定无论怎么样都不能做很好的映射
      • 由于是内存分页，所以不能单独把 A 村民的页面大小变小而 B 村民的页面大小不变
      • 只能改Manager类，那就不能让每个block存的信息改变

      所以说的话，应该是要调整页面大小了，这样的话和题目说的“在减少 record 使用 和 减少空置block 中作出平衡”相对应。

    • 解法：

      基于上述思考，我的方案是这样的：既然页面大小很大的时候 A 所占区域的未分配土地很多（页内碎片），那就直接让页面大小变小就好了。

      考虑怎么应用上一问的快速翻译的规律。

      1. 可以发现题目的GiveBlockTo是有可能交叉插入的，就是可能是这样：先给 A ，再给 B ，再给 A。这样的话不太好处理，因为每次动态改变页面大小的话，会出很多问题（比如，动态改变页面大小之后分给 A 的页面可能会包含之前 B 所占有的土地）。

        但仔细阅读题目，它说的是：**A，B村民只能通过连续排列的一个个编号找到自己的土地。**既然这样的话，那我们就可以：**先统计一下 A 和 B 各自一共申请了多少个土地，然后再给他们分配土地的实际位置。**这样的话最后 A 村民和 B 村民肯定也能获得到具体位置的土地，村长同样能根据 recorder 来找到实际的土地位置。

        那该怎么**在程序中确定当前插入的土地就是 A/B 村民最后的土地呢？**既然题目说可以改变GiveBlockTo函数，那就很好办，在GiveBlockTo中加入一个参数就好了。

        GiveBlockTo(int is_last){}

      这样的话，我们就可以得到最终 A 村民和 B 村民的土地总数，由于要利用快速翻译的规律，可以考虑二进制表示

      1. 上面说过若页面大小是$2^{k}$，那么村民A/B的相对编号（虚拟地址）就是实际编号（物理地址）的前k位，而实际编号（物理地址）从第k+1位起的部分就是页码。

        然后把玩一下数据可以发现这样一个规律：设 A 村民分配土地总数是A_have，B 村民分配土地总数是B_have，可以设定一个在k和k+1的划分，那么把A_have和B_have的二进制表示分别划分成前后两部分，那么前部分可以映射成需要的recorder的个数，后部分可以映射成 A 、B 村民在最后的页面所占的block个数。

        比如，A_have=$(00101)_{2}$，B_have=$(11111)_{2}$，在第 2 位和第 3 位之间切分，可以得到：

        00 | 101

        11 | 111

        对应的页面大小就是(1«3)=8，recorder就有1+(3+1)=5个，A 的最后一个页面有5个，B 的最后一个页面有8个，对应到图片上的话大概是：

        于是就把问题转化为了：该在什么地方进行划分才是最优的？也就是怎么才是最平衡的

        这样的话我们可以先定义一个估价函数：recorder个数sum_recorder和 A 和 B 所造成的未被分配的block总数sum_block（比如上面例子中的空白block就不算）的差值的绝对值：

        $$ abs(sum\_recorder-sum\_block) $$

        考虑怎么让这个估价函数最小。

        还是先把玩一下，发现使得估价函数最小的地方是不固定的，所以只能去**O(n)**地遍历每一位，然后找使得估价函数最少的地方。

    • 代码：

      由于题目说可以随意改动Manager类，那我就随意改了QWQ

      **注：**本题是 B 多于 A 的情况，但实际上 A 多于 B 或者有多个村民的情况可以进行同样的处理

      const int PAGE_SIZE = 32; //页面大小

const int MAX_PAGES = MAX_BLOCK_NUM / PAGE_SIZE; //最大页数


/* you can change every member in class "manager" !! */

class Manager {

private:

    Block Field[MAX_BLOCK_NUM];

    int BlockNum;

    int RecordSection;


    int A_have;  /* follow blocks owned by A*/

    int B_have; /* follow blocks owned by B*/

    int record_index; /* follow the record blocks*/


    int free_physical_pages[MAX_PAGES];

    int free_pages_cnt;


    int A_pages[MAX_PAGES];

    int A_pages_cnt;

    int B_pages[MAX_PAGES];

    int B_pages_cnt;


    int A_pool[PAGE_SIZE];

    int B_pool[PAGE_SIZE];

    int A_pool_index;

    int B_pool_index;


    int pool_index; // A_pool_index + B_pool_index


    bool is_cross_bound() {

        return record_index >= BlockNum || (A_have + B_have) >= record_index;

    }


    int allocate_physical_page() {

        if (free_pages_cnt <= 0) return -1;

        int p = free_physical_pages[--free_pages_cnt];

        return p;

    }


    // 把 A_pool 写入一个新的物理页并创建 recorder

    // 新增（或保留）的函数：当 pool 非空且需要 flush 时调用

    void flush_A_pool_if_needed_or_on_map() {

        if (A_pool_index == 0) return;

        int phys = allocate_physical_page();

        if (phys == -1) {

            std::cout << "can't find free page for A during flush" << std::endl;

            exit(1);

        }

        int page_index = A_pages_cnt;

        int map_from = page_index * PAGE_SIZE;

        int map_to = phys * PAGE_SIZE;

        if (record_index >= BlockNum) {

            std::cout << "ERROR: recorder region exhausted during A flush" << std::endl;

            exit(1);

        }

        Field[record_index++].Recordify(map_from, map_to, PAGE_SIZE, "A");

        A_pages[A_pages_cnt++] = phys;


        // 将 pool 依次分配到该物理页的 offsets 0..A_pool_index-1

        for (int i = 0; i < A_pool_index; ++i) {

            int offset = i;

            int phys_block = phys * PAGE_SIZE + offset;

            Field[phys_block].AllocateTo("A");

        }

        pool_index -= A_pool_index;

        A_pool_index = 0;

    }


    // 把 B_pool 写入一个新的物理页并创建 recorder

    void flush_B_pool_if_needed_or_on_map() {

        if (B_pool_index == 0) return;

        int phys = allocate_physical_page();

        if (phys == -1) {

            std::cout << "can't find free page for B during flush" << std::endl;

            exit(1);

        }

        int page_index = B_pages_cnt;

        int map_from = page_index * PAGE_SIZE;

        int map_to = phys * PAGE_SIZE;

        if (record_index >= BlockNum) {

            std::cout << "ERROR: recorder region exhausted during B flush" << std::endl;

            exit(1);

        }

        Field[record_index++].Recordify(map_from, map_to, PAGE_SIZE, "B");

        B_pages[B_pages_cnt++] = phys;


        for (int i = 0; i < B_pool_index; ++i) {

            int offset = i;

            int phys_block = phys * PAGE_SIZE + offset;

            Field[phys_block].AllocateTo("B");

        }

        pool_index -= B_pool_index;

        B_pool_index = 0;

    }


    void flush_all() {

        if (A_pool_index > 0) flush_A_pool_if_needed_or_on_map();

        if (B_pool_index > 0) flush_B_pool_if_needed_or_on_map();

    }


public:

    Manager(int blk_num, int record_sec) {

        BlockNum = blk_num;

        RecordSection = record_sec;

        record_index = record_sec;

        A_have = 0;

        B_have = 0;


        free_pages_cnt = 0;

        A_pages_cnt = 0;

        B_pages_cnt = 0;

        A_pool_index = 0;

        B_pool_index = 0;

        pool_index = 0;


        int phys_pages = RecordSection / PAGE_SIZE;

        if (phys_pages > MAX_PAGES) phys_pages = MAX_PAGES;

        for (int i = 0; i < phys_pages; ++i) {

            free_physical_pages[free_pages_cnt++] = i;

        }

    }


    // 改进Map 

    int Map(int id_to_map, std::string owner) {

        int page_index = id_to_map / PAGE_SIZE;

        int offset = id_to_map % PAGE_SIZE;

        if (owner == "A") {

            if (page_index < A_pages_cnt) {

                int phys = A_pages[page_index];

                return phys * PAGE_SIZE + offset;

            } else if (page_index == A_pages_cnt) {

                if (id_to_map >= A_have - A_pool_index && id_to_map < A_have) {

                    flush_A_pool_if_needed_or_on_map();

                    int phys = A_pages[page_index];

                    return phys * PAGE_SIZE + offset;

                } else {

                    return -1;

                }

            } else {

                return -1;

            }

        } else if (owner == "B") {

            if (page_index < B_pages_cnt) {

                int phys = B_pages[page_index];

                return phys * PAGE_SIZE + offset;

            } else if (page_index == B_pages_cnt) {

                if (id_to_map >= B_have - B_pool_index && id_to_map < B_have) {

                    flush_B_pool_if_needed_or_on_map();

                    int phys = B_pages[page_index];

                    return phys * PAGE_SIZE + offset;

                } else {

                    return -1;

                }

            } else {

                return -1;

            }

        } else {

            return -1;

        }

    }


    int GiveBlockToA() {

        /* GiveBlockToB similar to this one*/

        if (is_cross_bound()) {

            std::cout << "ERROR: cross bound" << std::endl;

            exit(1);

        }

        int logical_id = A_have;


        A_pool[A_pool_index++] = logical_id;

        ++A_have;

        ++pool_index;


        // 若 pool 满则一次性 flush

        if (A_pool_index == PAGE_SIZE) {

            flush_A_pool_if_needed_or_on_map();

        }


        // 这里是更一般的写法，当然用我前面所说的二进制的那个规律来写也可以

        int page_index = logical_id / PAGE_SIZE;

        int offset = logical_id % PAGE_SIZE;

        if (page_index < A_pages_cnt) {

            int phys = A_pages[page_index];

            return phys * PAGE_SIZE + offset;

        }

        return -1;

    }


    int GiveBlockToB() {

        if (is_cross_bound()) {

            std::cout << "ERROR: cross bound" << std::endl;

            exit(1);

        }


        int logical_id = B_have;

        B_pool[B_pool_index++] = logical_id;

        ++B_have;

        ++pool_index;


        if (B_pool_index == PAGE_SIZE) {

            flush_B_pool_if_needed_or_on_map();

        }


        int page_index = logical_id / PAGE_SIZE;

        int offset = logical_id % PAGE_SIZE;

        if (page_index < B_pages_cnt) {

            int phys = B_pages[page_index];

            return phys * PAGE_SIZE + offset;

        }

        return -1;

    }


    void print_the_field() {

        flush_all();


        /* print the alloction in field*/

        for (int i = 0; i < (BlockNum / 8); ++i) {

            for (int j = 0; j < 8; ++j) {

                int id = i * 8 + j;


                if (Field[id].type == "unallocated") {

                    std::cout << ".\t";

                } else if (Field[id].type == "allocated") {

                    std::cout << Field[id].owner << "\t";

                } else {

                    std::cout << "REC\t";

                }

            }


            printf("\n");

        }


        /* print the mapping for A*/

        std::cout << "For A" << std::endl;

        for (int i = 0; i < A_have; i++) {

            std::cout << "A" << i << " to Block" << Map(i, "A") << std::endl;

        }


        /* print the mapping for B*/

        std::cout << "For B" << std::endl;

        for (int i = 0; i < B_have; i++) {

            std::cout << "B" << i << " to Block" << Map(i, "B") << std::endl;

        }

    }


};
