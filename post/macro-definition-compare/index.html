C 语言：利用宏定义比较两个数大小

常规

基础宏定义法

正常来讲，如果想要 比较 两个数 的 大小，可以直接用 >、< 或 if，大概是这样：

#include <iostream>

#define max(a, b) ((a) > (b) ? (a) : (b))

int main() {
    std::cout << max(1, 2) << '\n';

    return 0;
}

// 输出 2

安全宏定义法

但上面那样有个问题，就是 宏替换 中的 表达式 会 重复求值，比如 max(i++, 2)，它就是这样：

(i++) > (2) ? (i++) : (2)

如果 (i++) > (2) 成立，后面还会执行一遍 i++

所以为了解决这个问题，可以用 GCC 的 语句表达式，将 代码块 作为 表达式，大概是这样：

#include <iostream>

#define max(a, b) ({    \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    _a > _b ? _a : _b;  \
})

int i;
int get() {
    return ++i;
}

int main() {
    std::cout << max(get(), 0) << '\n';

    return 0;
}

// 输出 1

泛型宏定义法

上面说的都是关于整数的比较，但 浮点数 的 判断是否相等 由于有 精度问题 不能这样直接比，而且万一 a 的 类型 和 b 的 类型 不一致，该怎么办呢？

C11 引入了 _Generic 来做 按类型分派，也就是常说的 泛型宏，可以解决类型不一致的问题

下面用 C 来写，_Generic 是 C11 特性，同时仍依赖 GCC 的 typeof 和语句表达式

#include <stdio.h>

#define generic_max(a, b) ({ \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    _Generic((_a), \
        int: _Generic((_b), \
            int: _a > _b ? _a : _b, \
            float: (double)_a > _b ? (double)_a : _b, \
            double: (double)_a > _b ? (double)_a : _b \
        ), \
        float: _Generic((_b), \
            int: _a > (double)_b ? _a : (double)_b, \
            float: _a > _b ? _a : _b, \
            double: _a > _b ? _a : _b \
        ), \
        double: _Generic((_b), \
            int: _a > (double)_b ? _a : (double)_b, \
            float: _a > (double)_b ? _a : (double)_b, \
            double: _a > _b ? _a : _b \
        ) \
    ); \
})

#define float_equal(a, b) ({ \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    (_a - _b) < 1e-6 && (_b - _a) < 1e-6; \
})

#define generic_equal(a, b) ({ \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    _Generic((_a), \
        int: _Generic((_b), \
            int: (_a == _b), \
            float: float_equal((double)_a, _b), \
            double: float_equal((double)_a, _b) \
        ), \
        float: _Generic((_b), \
            int: float_equal(_a, (double)_b), \
            float: float_equal(_a, _b), \
            double: float_equal(_a, _b) \
        ), \
        double: _Generic((_b), \
            int: float_equal(_a, (double)_b), \
            float: float_equal(_a, (double)_b), \
            double: float_equal(_a, _b) \
        ) \
    ); \
})

float i;
float get() {
    return i += 0.1f;
}

int main() {
    i = 0.0f;
    printf("%f\n", generic_max(get(), 0));

    i = 0.0f;
    printf("%d\n", generic_equal(get(), 0.1f));

    return 0;
}

/* 输出
0.100000
1
*/

进阶

上面都是用的 >、<，那有没有一种办法，可以不用 >、< 或 if 呢？

这个时候可以想一下，判断大小还是看 a - b 是 大于 0 还是 小于 0，所以可以用 a - b 得到的值去判断，直接看 符号位 即可

有溢出版本

直接写的话应该是这样：

#include <iostream>

#define max(a, b) ({    \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    (_a - _b) >> (sizeof(_a) * 8 - 1) ? _b : _a; \
})

int i;
int get() {
    return ++i;
}

int main() {
    std::cout << max(get(), 0) << '\n';

    return 0;
}

// 输出 1

但这样有个问题，即使按 sizeof(_a) 取符号位，_a - _b 仍有可能 溢出，在 C 里有符号整数溢出是 UB，需要解决这个溢出问题

无溢出版本

可以直接转成 unsigned，也就是 无符号整数，相减时按模运算，不会触发有符号溢出 UB

然后可以提取 a 的 符号位、b 的 符号位，以及 a 和 b 的 差值 c 的 符号位，根据：

  • 同号相减 不可能溢出
  • 异号相减 可能溢出

来进行判断：

  • 同号相减 时，不可能溢出，直接看 差值 c 的 符号
  • 异号相减 时，可能溢出，看 a 的 符号：
    • a 是 负数，b 就是 正数，a < b
    • a 是 正数，b 就是 负数，a > b

这样就可以 避开有符号减法溢出

那代码该怎么写呢？可以用一个 位运算：

// _use_sign_a 在 a 与 b 异号时为 1，同号时为 0
// _use_sign_c 在 a 与 b 异号时为 0，同号时为 1
// _sa 是 a 的符号，_sc 是 c 的符号
int _k = (_use_sign_a & _sa) | (_use_sign_c & _sc);

然后后面的结果就可以利用 _k 来取最大值：

// _k 为 1 时 -_k 就是全 1，为 0 时 -_k 就是全 0
_a ^ ((_a ^ _b) & -_k);

不过这里还有个小问题，就是直接写 unsigned 其实是 unsigned int，并不能适配 long long 等类型

但 C 语言不支持 unsigned typeof()，这里可以用 C++ 的 std::make_unsigned，所以可以这么改：

#define max(a, b) ({ \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    typedef typename std::make_unsigned<typeof(_a)>::type _unsigned_type; \
    int _shift = sizeof(_a) * 8 - 1; \
    int _sa = ((_unsigned_type)_a >> _shift) & 1; \
    int _sb = ((_unsigned_type)_b >> _shift) & 1; \
    int _sc = (((_unsigned_type)_a - (_unsigned_type)_b) >> _shift) & 1; \
    int _use_sign_a = _sa ^ _sb; \
    int _use_sign_c = 1 ^ _use_sign_a; \
    int _k = (_use_sign_a & _sa) | (_use_sign_c & _sc); \
    _a ^ ((_a ^ _b) & -_k); \
})

所以整个代码如下：

#include <iostream>
#include <type_traits>

#define max(a, b) ({ \
    typeof(a) _a = (a); \
    typeof(b) _b = (b); \
    typedef typename std::make_unsigned<typeof(_a)>::type _unsigned_type; \
    int _shift = sizeof(_a) * 8 - 1; \
    int _sa = ((_unsigned_type)_a >> _shift) & 1; \
    int _sb = ((_unsigned_type)_b >> _shift) & 1; \
    int _sc = (((_unsigned_type)_a - (_unsigned_type)_b) >> _shift) & 1; \
    int _use_sign_a = _sa ^ _sb; \
    int _use_sign_c = 1 ^ _use_sign_a; \
    int _k = (_use_sign_a & _sa) | (_use_sign_c & _sc); \
    _a ^ ((_a ^ _b) & -_k); \
})

int main() {
    long long x = 9223372036854775807LL;
    long long y = -9223372036854775807LL - 1;
    std::cout << max(x, -1LL) << '\n';
    std::cout << max(y, 0LL) << '\n';
    return 0;
}

/* 输出
9223372036854775807
0
*/
